# Happy Day Toronto WordPress Theme

Custom WordPress and WooCommerce theme for
[Happy Day Toronto](https://happydaytoronto.com).

## What this repository contains

- Custom page and service templates
- WooCommerce presentation and storefront integrations
- Responsive navigation, forms, FAQ sections, blog templates, and footer
- Theme-owned CSS, JavaScript, fonts, icons, and map assets

## Deployment

The repository root is the WordPress theme directory:

```text
wp-content/themes/happy-day
```

Production deployments update theme code only. WordPress content, settings,
orders, products, database records, plugins, and media uploads are managed
separately and must never be overwritten by a theme deployment.

## Requirements

- WordPress
- WooCommerce
- Contact Form 7
